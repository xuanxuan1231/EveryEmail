# 快速添加 Microsoft 365 账号

## 🚀 快速开始（5 分钟）

### 步骤 1：创建 Azure 应用（一次性设置）

1. **访问 Azure 门户**
   - 打开 https://portal.azure.com/
   - 登录你的 Microsoft 账号

2. **创建应用注册**
   - 搜索 "Microsoft Entra ID"
   - 左侧菜单 → "应用注册" → "新注册"
   - 填写：
     - 名称：`EveryEmail`
     - 账户类型：**"任何组织目录中的账户和个人 Microsoft 账户"**
     - 重定向 URI：
       - 平台：**"移动和桌面应用程序"**
       - URI：`com.everyemail.app://oauth2redirect`
   - 点击 "注册"

3. **添加 API 权限**
   - 进入刚创建的应用
   - 左侧菜单 → "API 权限" → "添加权限"
   - 选择 "Microsoft Graph" → "委托的权限"
   - 搜索并添加：
     - ✅ `Mail.ReadWrite`
     - ✅ `Mail.Send`
     - ✅ `User.Read`
     - ✅ `offline_access`
     - ✅ `openid`
     - ✅ `email`
     - ✅ `profile`
   - 点击 "添加权限"

4. **获取客户端 ID**
   - 左侧菜单 → "概述"
   - 复制 **"应用程序(客户端) ID"**
   - 格式：`12345678-1234-1234-1234-123456789abc`

---

### 步骤 2：配置应用

运行应用时传入客户端 ID：

```bash
flutter run --dart-define=MS_OAUTH_CLIENT_ID=你的客户端ID
```

**完整示例：**
```bash
flutter run \
  --dart-define=MS_OAUTH_CLIENT_ID=12345678-1234-1234-1234-123456789abc
```

---

### 步骤 3：添加账号

1. **打开应用**
   - 点击 "添加账户"

2. **输入邮箱**
   - 输入你的 Microsoft 邮箱
   - 支持的域名：
     - `@outlook.com`
     - `@hotmail.com`
     - `@live.com`
     - `@msn.com`
     - 或你的组织域名（如 `@contoso.com`）

3. **自动识别**
   - 应用自动识别为 Microsoft 账号
   - 跳转到 OAuth 登录

4. **完成登录**
   - 在浏览器中登录 Microsoft 账号
   - 授权应用访问邮件
   - 自动返回应用并开始同步

## ❓ 常见问题

### Q: 为什么需要创建 Azure 应用？
A: Microsoft 要求所有使用 Graph API 的应用都必须注册。这是安全要求。

### Q: 客户端 ID 安全吗？
A: 是的。客户端 ID 是公开的，不是密钥。真正的认证通过 OAuth 流程完成。

### Q: 支持多个账号吗？
A: 是的！你可以添加多个 Microsoft 账号。

### Q: 工作账号需要管理员同意吗？
A: 取决于你的组织策略。如果需要，请联系 IT 管理员。

### Q: 数据存储在哪里？
A: 所有数据存储在你的设备本地，不会上传到任何服务器。

## 🔧 故障排除

### 问题：OAuth 登录失败

**检查清单：**
- ✅ 客户端 ID 是否正确？
- ✅ 重定向 URI 是否为 `com.everyemail.app://oauth2redirect`？
- ✅ API 权限是否已添加？
- ✅ 网络连接是否正常？

**解决方法：**
1. 重新检查 Azure 应用配置
2. 确认客户端 ID 没有多余空格
3. 重启应用重试

### 问题：只能看到收件箱

**原因：** 文件夹同步未完成

**解决方法：**
1. 等待几秒钟
2. 打开侧边栏查看文件夹列表
3. 点击刷新按钮

### 问题：提示"需要管理员同意"

**原因：** 你的组织要求管理员批准应用

**解决方法：**
1. 联系 IT 管理员
2. 让管理员在 Azure 门户中授予同意
3. 或使用个人 Outlook.com 账号测试
